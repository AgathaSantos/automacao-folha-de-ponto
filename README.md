# 📊 Automação da Folha de Ponto

Projeto desenvolvido em **Python** com o objetivo de automatizar parte do processo de conferência e organização de folhas de ponto.

A solução foi desenvolvida a partir de uma necessidade identificada no ambiente de trabalho, buscando reduzir tarefas manuais, agilizar a conferência das informações e diminuir a possibilidade de erros.

## 🚀 Objetivo

Automatizar o processo de:

* Leitura de arquivos PDF;
* Extração de informações das folhas de ponto;
* Identificação das funcionárias;
* Conferência dos dados com uma planilha Excel;
* Organização dos resultados;
* Geração de uma planilha final para conferência;
* Automatização do envio dos arquivos pelo WhatsApp.

## 🛠️ Tecnologias utilizadas

* **Python**
* **PDFPlumber** — leitura e extração de dados dos PDFs
* **Pandas** — tratamento e organização dos dados
* **OpenPyXL** — manipulação de arquivos Excel
* **PyAutoGUI** — automação de tarefas no computador
* **WhatsApp Web** — envio automatizado dos arquivos

## ⚙️ Como funciona

O processo funciona basicamente da seguinte forma:

```text
PDFs das folhas de ponto
          ↓
Leitura e extração dos dados
          ↓
Identificação da funcionária
          ↓
Conferência com a planilha Excel
          ↓
Organização dos resultados
          ↓
Geração da planilha de conferência
          ↓
Envio automatizado pelo WhatsApp
```

## 📈 Resultado

A automação foi criada para transformar um processo que dependia de diversas etapas manuais em um fluxo mais rápido e organizado.

Além de reduzir o tempo gasto na conferência, o projeto contribui para:

* Redução de tarefas repetitivas;
* Maior organização das informações;
* Diminuição de erros manuais;
* Padronização do processo;
* Ganho de produtividade.
